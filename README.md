C Programming Projects

A collection of C programming projects developed to practice fundamental programming concepts, including arrays, structures, pointers, functions, loops, conditional statements, and file handling.
This repository contains two programs that demonstrate how C programming can be used to solve mathematical problems and manage student information.

📌 Projects Included

1. Matrix Multiplication

Description:
A C program that multiplies two matrices and displays the resultant matrix. The program accepts matrix dimensions and elements from the user and checks whether multiplication is possible before performing the calculation.
Features:
Accepts the dimensions of two matrices.
Takes matrix elements as input.
Checks whether matrix multiplication is possible.
Calculates the resultant matrix using nested loops.
Displays the resultant matrix in tabular form.
Concepts Used:
Two-dimensional arrays
Nested loops
Conditional statements
Arithmetic operations
User input and output

Sample Output:
Enter rows and columns for first matrix: 2 2
Enter rows and columns for second matrix: 2 2

Enter elements of first matrix:
1 2
3 4

Enter elements of second matrix:
5 6
7 8

Resultant Matrix:
19      22
43      50
Expected Result:
The program multiplies the two matrices and displays the resulting matrix



2. Student Record & Result Management System

Description:
A menu-driven C program that manages student records and calculates academic results. It allows users to add student information, display records, search for students using their roll numbers, and save or retrieve records using file handling.

Features:
Add student records, including roll number and name.
Accept marks in three subjects.
Calculate total marks and average using pointers.
Display all student records in tabular form.
Search for a student by roll number.
Save records to a binary file.
Retrieve and display previously saved records.
Provide a menu-driven interface for easy navigation.

Concepts Used:
Structures
Arrays of structures
Pointers and pointer arithmetic
Functions and function prototypes
Loops and conditional statements
File handling using fopen(), fwrite(), and fread()
String input and formatted output
